# Definition of Done

This document defines the minimum quality requirements that every milestone must satisfy before it can be considered complete.

A milestone is considered complete only when all of the following conditions are met.

---

## Implementation

- Feature implemented
- Public API reviewed
- Internal structure reviewed

---

## Testing

- Unit tests added
- Existing tests pass
- Edge cases covered

---

## Code Review

- Naming reviewed
- Responsibilities reviewed
- Duplication reviewed

---

## Architecture Review

- Architecture validated
- ADRs updated if needed

---

## Documentation

- ROADMAP updated
- LESSONS_LEARNED updated
- Relevant documentation updated

---

## Delivery

- Commit created
- Version tag created
